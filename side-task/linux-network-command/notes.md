## Linux Network Commands

# Tujuan:
- Memahami basic commands yang ada di Linux untuk cek ip jaringan, kondisi, dsb.

# Commands:
- ip a
- ip route
- ping 8.8.8.8

# Insight:
- ip a:
    - Menampilkan IP pc yang dipakai sekarang dan interfacenya.
- ip route:
    - Menampilkan gateway pc yang trhubung ke router.
- ping 8.8.8.8:
    - Untuk mengecek apakah pc terhubung dengan internet atau tidak.
