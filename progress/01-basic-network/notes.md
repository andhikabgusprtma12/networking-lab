# Tujuan Lab:
- Untuk memahami cara kerja jaringan secara basic dan juga mempelajari bagaimana jika jaringan trsebut berada di satu network, beda network, dan bahkan sampai dua network yang berbeda bisa saling terkoneksi.

# Hasil:
- Secara hasil:
    - Jaringan yang berada di satu network yang sama bisa saling terkoneksi.
    - Jaringan yang berbeda network tidak bisa saling terkoneksi.
    - Sedangkan jaringan yang berbeda network tetapi harus bisa saling terkoneksi harus memerlukan Router untuk bisa saling terkoneksi.
## Hasil lebih lengkap bisa di cek di folder images

# Analisis
- Kenapa jaringan yang satu network bisa saling terkoneksi?
    - Karena berada dalam network address / IP yang sama dan Subnet Mask yang sama.
- Kenapa jaringan yang berbeda network tidak bisa saling terkoneksi?
    - Karena berbeda dalam network address / IP walaupun Subnet Mask sama.

# Solusi
- Solusi terbaik untuk menghubungkan dua network yang berbeda adalah menggunakan Router, dengan cara mengisi IP di Router sebagai gateway untuk dua device di kolom gateway.
